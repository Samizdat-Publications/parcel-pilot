# Parcel Pilot

An arcade sky-courier game built in Godot 4.7, where **every model is generated by Python
scripts in Blender** and every sound is synthesized by code. No downloaded assets.

Work in progress. See `docs/DESIGN.md` for the spec and `docs/PROMPT.md` for the brief.

## Layout

```
blender/   procedural model generators (the source of truth for every mesh)
tools/     build and verification scripts
game/      the Godot project (res://)
docs/      design, plan, previews, devlog captures
```

## Rebuild the models

```bash
python tools/build_assets.py
```
